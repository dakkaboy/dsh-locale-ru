# Русский русификатор DeepSeek Harness — глоссарий и правила перевода

Переводим интерфейс веб-клиента DeepSeek Harness (DSH) с английского на русский.
Строки — короткие подписи UI: кнопки, пункты меню, заголовки, подсказки, плейсхолдеры полей,
статусы, тексты ошибок и пустых состояний.

## Жёсткие правила

1. Перевести **все** значения. Ключи не менять, не добавлять и не удалять. Структура JSON та же.
2. Плейсхолдеры вида `{name}`, `{count}`, `{size}`, `{model}`, `{total}` сохранять дословно,
   в том же количестве. Порядок слов вокруг них может меняться.
3. Сохранять ведущие и замыкающие пробелы, если они есть.
4. Сохранять разметку: `<code>…</code>`, `<b>…</b>`, `**…**`, обратные кавычки, переводы строк `\n`.
5. Сохранять символы «…», «—», «·», «/», стрелки и emoji как в оригинале.
6. Точку в конце не добавлять, если её нет в оригинале; не убирать, если есть.
7. Не переводить: названия продуктов и брендов (DeepSeek, DSH, Harness, GitHub, MCP, VS Code,
   Codex, Anthropic, OpenAI, Google, Kimi, Qwen, GLM, SenseVoice, LibreOffice, Windows, macOS, Linux),
   аббревиатуры (API, JSON, YAML, HTML, CSS, CLI, IDE, URL, ID, SDK, PDF, CSV, OAuth, HTTP, MCP),
   имена файлов, расширения, пути, горячие клавиши (Cmd/Ctrl+Enter, Shift+Tab), названия моделей.
8. Стиль UI: коротко, без канцелярита, без «Вы» с большой буквы. Обращение к пользователю — на «вы»,
   но в подписях кнопок обычно инфинитив: «Отправить», «Отмена», «Удалить».
9. Заголовки и пункты меню — с заглавной буквы, без точки. Статусы — с заглавной буквы.
10. Не калькировать английский порядок слов, если по-русски это звучит неестественно. Краткость важна:
    строка должна влезать в кнопку/меню. Русский текст обычно длиннее на 15–30 % — избегать лишних слов.
11. Английские кавычки `"…"` внутри строк заменять на «ёлочки», если это цитата в тексте.
12. Если исходник — китайский (помечен `[zh] ` в начале), перевести по смыслу, маркер `[zh] ` в перевод не включать.

## Формат результата

Файл `translate/ru-<ID>.json` — тот же объект `{ "<namespace>": { "<key>": "<русский текст>" } }`,
UTF-8, отступ 2 пробела. Проверка:

```
node tools/check-partial.js translate/batch-<ID>.json translate/ru-<ID>.json
```

Должно быть `OK …`. Ошибки (ERROR) — исправить обязательно; предупреждения (warn) — по смыслу
(«unchanged» допустимо только для брендов и технических строк).
